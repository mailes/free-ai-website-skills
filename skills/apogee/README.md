# APOGEE — Orbital & Launch Propulsion Engineering Template

A self-contained, zero-dependency Swiss-precision aerospace engineering landing page. Runs 100% offline over `http://` or directly via `file://` with local `Plus Jakarta Sans` & `Inter` fonts (SIL OFL 1.1) and 3 MIT-derived aerospace videos.

## Included Files
- `index.html` — Complete responsive site with scroll-expanding launchpad video hero, interactive Engine × Orbit × Payload propulsion mission configurator, expandable vertical manufacturing tolerance matrix, dark carbon qualification telemetry band, test-stand video diptych, and honest local Mission RFQ form.
- `assets/fonts/` — Local `Plus Jakarta Sans` + `Inter` (400–700, OFL) with licenses.
- `assets/video/` — 3 lightweight H.264 aerospace loops (`hero-launch.mp4`, `orbit-horizon.mp4`, `night-pad.mp4`), MIT-licensed.
- `SOURCES.md` — Per-file license and SHA-256 ledger.
