# Alder Dental
Open index.html in a current browser. The static site includes a service index, visit information, and a local visit-brief form. No submission, payments, or booking provider is connected. The practice and contact details are fictional. Images are generated illustrations for this project.

Edit the practice name, metadata, visit details and headings in index.html. Update the services array to change service titles, descriptions and corresponding asset filenames. The form's purpose options are derived from the same records. The appointment form should only be connected to an actual provider after the privacy and contact details for the adapted site are written.
